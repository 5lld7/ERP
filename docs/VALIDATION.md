# سجل تحقق النسخة

## تحديث دعم Vercel — 19 أكتوبر 2026

- أُضيف مدخل Python لـVercel وملف إعادة كتابة API وتقديم الواجهة من `static`، ودعم قاعدة Turso بواسطة SDK الرسمي `libsql`.
- نجحت **35 حالة اختبار مع SQLite و35 حالة مع libSQL محليًا**. تشمل الحالات الجديدة حماية المدير الأول برمز، حفظ الجلسات والبيانات ومحاولات الدخول عند إعادة تهيئة مدخل الوظيفة، تحويل المسار وإرجاع 503 عند غياب القاعدة الدائمة بدل إنشاء قاعدة مؤقتة.
- نجح اختبار المتصفح الكامل مع `--entrypoint vercel` ومحرّك libSQL محلي، بما فيه رمز إعداد المدير والمعاملات والمرفقات والرواتب والـQR والتقارير وتخطيط الهاتف.
- لم يُجر نشر داخل حساب Vercel أو اتصال بقاعدة Turso حقيقية؛ لم تتوفر متغيرات الاتصال أو تفويض حساب Vercel. طلب قراءة API لـVercel من هذه البيئة أرجع حجب CONNECT برمز 403 من وسيط الشبكة. دليل الخطوات المطلوبة في [VERCEL.md](VERCEL.md).
- النتائج السابقة للنسخة المحلية مذكورة أدناه؛ لا يُفترض استمرار عامل النسخ المحلي داخل وظيفة Vercel.

تم التحقق في بيئة Codex بتاريخ 18 أكتوبر 2026، باستخدام Python 3.12 وChromium الفعلي. جميع بيانات الاختبار في قواعد مؤقتة مستقلة، ولم يُنشأ مستخدم أو بيانات تجريبية في قاعدة الشركة الأساسية.

## النتائج

- **27 اختبار وحدة وHTTP ناجحًا**: الشراء والبيع والتحصيل والمرتجعات، إلغاء المعاملة كاملة عند فشل سطر، منع المخزون السالب، الترحيل مرة واحدة، تحويل أمر الشراء، إعادة تحقق المرتجعات وقت الترحيل، توزيع الخصم، حد الائتمان، الصلاحية، التحويل والجرد حتى الصفر، رفض القيد غير المتوازن، الرواتب والسلف والخصومات والإضافي والمكافآت، الإجازات، الإهلاك، التقارير، كلمات المرور، الصلاحيات وCSRF، حظر الوصول الإداري لحساب القراءة، مرفقات الموظفين وQR، تصدير آمن لـCSV، النسخ والاستعادة والتحقق من سلامة القاعدة وتدوير النسخ.
- **اختبار متصفح ناجح**: إعداد المدير الأول، تحميل تجريبي اختياري، إنشاء صنف والبحث، ملصقات باركود وQR، فاتورة شراء، بيع من نقطة البيع، تحصيل المتبقي، رواتب أربعة موظفين، رفع عقد موظف، تحديث مرحلة معاينة وتحويلها لفاتورة، ميزان مراجعة متوازن، تجميع المبيعات شهريًا وتصدير CSV.
- عُرضت 18 شاشة إدارة إضافية بلا أخطاء JavaScript، واختُبرت قائمة الهاتف وتخطيط بعرض 390 بكسل بدون تمدد أفقي للصفحة. الجداول العريضة تقبل التمرير داخل مساحتها.
- فحص صياغة JavaScript ناجح. لا توجد مرحلة بناء واجهة لازمة لتشغيل هذا المشروع.
- أُعيد تنفيذ التثبيت من السكربت، وتهيئة القاعدة قابلة للتكرار، وشُغّل الخادم من سكربت التشغيل، وتأكد رد `auth` بحالة إعداد أولي بدون حساب افتراضي.
- نُفذ النسخ التلقائي عند التشغيل وتأكد اكتماله. لم يُنتظر مرور 24 ساعة فعليًا؛ التكرار الزمني موضح في عامل النسخ ومضبوط بفاصل قابل للتعديل.
