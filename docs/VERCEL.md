# نشر مدار على Vercel

ملفات النشر جاهزة في `vercel.json` و`api/index.py`. الواجهة تُقدم من CDN، وطلبات `/api/*` تصل إلى Python Function، وتتصل بقاعدة Turso دائمة بواسطة SDK الرسمي `libsql` المثبّت مع تحقق SHA-256. لا تُستخدم قاعدة SQLite داخل `/tmp` لحفظ بيانات الشركة.

## 1. قاعدة البيانات

أنشئ حسابًا وقاعدة على [Turso](https://turso.tech)، أو أضف تكامل Turso المتاح لحسابك من Marketplace في Vercel. إذا لم يظهر التكامل، استخدم لوحة Turso مباشرة.

احتفظ برابط القاعدة (`libsql://…turso.io`) ورمز وصول يسمح بالقراءة والكتابة. أضفهما مباشرة إلى متغيرات مشروع Vercel؛ لا تضع الرمز في المستودع أو المحادثة. اختر منطقة للقاعدة قريبة من منطقة وظيفة Vercel لتقليل زمن العمليات.

قاعدة Turso الجديدة تبدأ فارغة. قاعدة SQLite المحلية لا تنتقل تلقائيًا؛ إذا أضفت بيانات فعلية محليًا، خذ نسخة متحققة واستوردها بأدوات Turso الموثقة قبل تحويل الاستخدام، ولا تنشئ شركة ثانية بالخطأ.

## 2. استيراد المشروع

من حساب Vercel اختر **Add New → Project**، ثم استورد مستودع `5lld7/ERP` بعد وجود ملفات المشروع فيه. بديلًا لذلك يمكن نشر نسخة المشروع المحلية بواسطة Vercel CLI بعد تسجيل الدخول من جهازك.

الإعدادات:

- Framework Preset: **Other**.
- Root Directory: جذر المستودع.
- Output Directory: `static`؛ مضبوط في الملف.
- لا توجد عملية بناء JavaScript مطلوبة.
- Python: `3.12`، مثبت في `.python-version`.
- لا تعدّل مسارات إعادة كتابة `/api/*`، ولا تضف `server.py` إلى أمر Start دائم؛ Vercel يشغّل `api/index.py` لكل طلب.

## 3. المتغيرات الآمنة

من **Project → Settings → Environment Variables** أضف:

| الاسم | القيمة |
| --- | --- |
| `ERP_DATABASE_URL` | الرابط الحقيقي لقاعدة Turso |
| `ERP_DATABASE_TOKEN` | رمز اتصال القاعدة، كقيمة حساسة |
| `ERP_SETUP_TOKEN` | قيمة عشوائية طويلة تختارها وتحتفظ بها، لإنشاء المدير الأول فقط |
| `ERP_COOKIE_SECURE` | `1` |
| `ERP_BACKUP_INTERVAL_HOURS` | `0` |

لا تستخدم بادئات عامة مثل `NEXT_PUBLIC_` أو `VITE_` لهذه القيم. ملفات `.env` وإعدادات `.vercel` والبيانات المحلية مستثناة من Git ومن رفع Vercel. `ERP_SETUP_TOKEN` يجب أن يكون 32 حرفًا عشوائيًا على الأقل؛ أدخله في شاشة التأسيس بنفسك، فهو يمنع أي زائر آخر من إنشاء مدير قبل صاحب المشروع. لا توجد كلمة مرور افتراضية.

خصص **قاعدة مختلفة** للـPreview عن Production إذا فعّلت متغيرات Preview؛ مشاركة القاعدة تجعل تجارب الفروع تعدّل بيانات الشركة الفعلية. لا تنشئ بيانات تجريبية في قاعدة مستخدمة فعليًا.

## 4. النشر والتفعيل

اضغط **Deploy**. بعد إضافة أو تغيير متغيرات البيئة نفذ **Redeploy** لكي تُحقن القيم في الوظائف الجديدة.

افتح الرابط الذي يصدره حساب Vercel نفسه، ثم:

1. تحقق من ظهور شاشة إنشاء الشركة، وعدم ظهور خطأ قاعدة البيانات.
2. أدخل رمز إعداد المدير الأول، واسم الشركة، واسم المدير وكلمة مرور قوية.
3. سجّل عملية تجريبية في قاعدة منفصلة، ثم افتح التطبيق في جلسة جديدة وتحقق من بقائها.
4. راجع **Functions Logs** إذا ظهر 503. الرسالة تعني أن متغيرات القاعدة أو اتصالها أو `ERP_COOKIE_SECURE=1` غير مكتملة، ولا تتحول الخدمة إلى قاعدة مؤقتة عند الفشل.

القوائم والقيود والمخزون والجلسات ومحاولات الدخول ومرفقات الموظفين تبقى في Turso. يعاد استخدام ترقيم الجداول والمعاملات الصريحة؛ فشل العملية يرجع كامل المعاملة كما في النسخة المحلية. تهيئة المخطط تتم عند أول اتصال وتُسلسل داخل معاملة لمنع تكرار البيانات عند بدء عدة وظائف.

## النسخ والحدود

- لا يعمل عامل النسخ كل 24 ساعة داخل وظيفة Vercel. فعّل الحفظ/الاستعادة والتصدير من أدوات Turso حسب خطتك.
- تنزيل النسخة اليدوية من التطبيق متاح للمدير للنسخ الصغيرة، ويُنشئ لقطة SQLite متسقة تشمل المرفقات. يرفض التطبيق تنزيل نسخة أكبر من 4 ميجابايت من وظيفة Vercel؛ استخدم تصدير Turso للنسخ الأكبر. لا تعتمد على ملفات `/tmp` بعد انتهاء الطلب.
- تشغيل المتصفح لا يثبت وحده اتصال Turso الفعلي. يجب التحقق من النشر باستخدام قاعدة حقيقية وبيانات حسابك.
- التطبيق لا يرسل الأموال ولا يصدر فاتورة حكومية معتمدة؛ تبقى حدود التكامل الموضحة في دليل النظام.

## التحقق في بيئة التطوير

```bash
bash scripts/install.sh
.venv/bin/python -m unittest discover -s tests -v
ERP_DB_DRIVER=libsql .venv/bin/python -m unittest discover -s tests -v
python3 tests/browser_smoke.py --entrypoint vercel
```

تختبر الأوامر قواعد مؤقتة فقط. الاختبار الثاني يستخدم محرّك libSQL الحقيقي محليًا، والثالث يستخدم مدخل Vercel مع قاعدة محلية مؤقتة ورمز إعداد. هذه الاختبارات لا تدعي تشغيلًا على بنية Vercel أو اتصالًا بخدمة Turso قبل توفير الحسابات والمتغيرات وإجراء النشر الفعلي.
